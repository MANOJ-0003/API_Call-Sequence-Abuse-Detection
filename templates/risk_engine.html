🗺️ Expected Business-State Transitions

Every commerce API has explicit prerequisite states that must be satisfied:

API: products Requires: login
API: add-to-cart / cart Requires: products
API: checkout Requires: add-to-cart
API: pay Requires: checkout
Honeypots: /api/* 🚫 Zero-Tolerance Quarantine

⚙️ Multi-Tier Adaptive Mitigations

How the engine dynamically responds based on behavioral trust score:

🟢 Trust Score 80–100 — Normal
100 req/min rate limit. Normal workflow allowed. No restrictions.
🟡 Trust Score 50–79 — Suspicious
Rate limit tightened to 20 req/min. Progressive cooldown: 5s → 15s → 30s per violation.
🟠 Trust Score 0–49 — High Risk
Rate limit reduced to 5 req/min. Workflow locked. Step-Up Verification required for checkout/pay.
🔴 Critical Violation — Quarantine + Revocation
Session quarantined and revoked. All sensitive API access blocked. Must re-authenticate.
